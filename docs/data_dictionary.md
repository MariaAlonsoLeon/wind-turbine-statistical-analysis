# Diccionario de datos

Fuente: `data/raw/data_description.txt` (Bassi, Rodrigues y Sauer, 2023,
DOI [10.5281/zenodo.7348454](https://doi.org/10.5281/zenodo.7348454)).

Convenciones de esta tabla:

* **Descripción original**: copiada literalmente del diccionario (en inglés).
* **Unidad**: solo la que figura en el diccionario. Si no figura:
  *No documentada*.
* **Nombre en R**: nombre limpio asignado en `scada_schema()` (`R/01_io.R`),
  que es la fuente única de este mapeo.
* **Observado (2017)**: lo que muestran los datos de 2017, **no** lo que dice
  el diccionario. Debe revisarse con los ficheros 2018–2022
  (`outputs/tables/quality_ranges.csv` y `quality_status_codes.csv` se
  regeneran automáticamente).

## Información general del fichero (documentada)

| Aspecto | Documentación original |
|---|---|
| Frecuencia | "1 record per minute" |
| Ficheros | `data_swt_iee_usp_YYYY.csv`, uno por año |
| Separador | `;` |
| Decimal | `.` |
| Cabecera | primera línea de cada fichero |

Observaciones de formato (2017, no documentadas):

* La cabecera de `T1` aparece como `" T1"` (espacio inicial). Se recortan
  espacios al leer.
* El separador de milisegundos de `Log Time` alterna entre `.` y `,` (cambia a
  partir del registro 17 716). Se normaliza a `.`.
* Fin de línea CRLF (Windows); `readr` lo gestiona sin intervención.
* El fichero de 2017 solo cubre del 29/11/2017 al 31/12/2017.

## Códigos y estados operativos

**El diccionario no documenta el significado de ningún código.** No se
asigna ningún significado (p. ej. "funcionamiento normal") a ningún valor.
Frecuencias observadas en 2017 (% de registros):

| Variable | Códigos observados |
|---|---|
| Turbine status | 1 (39,3), 3 (32,6), 0 (20,4), 8 (6,4), 33 (1,2), 35 (0,1), 32 (1 registro), 256 (1 registro) |
| Grid status | 0 (60,7), 4104 (31,9), 4096 (7,4), 1024 / 5120 / 5376 (2 registros cada uno) |
| System status | 0 (40,6), 1024 (32,7), 256 (26,7), 1056 (2 registros) |
| Slave Status | 0 (94,6), 32768 (5,4) |
| Event status | 8 (37,0), 0 (31,1), 2 (20,3), 1024 (4,7), 4104 (3,2), 32768 (2,5), 5120 (0,5), 1001 (0,5) |
| Last event code | 11 (40,3), 111 (31,1), 107 (20,3), 12 (5,3), 52 (2,5), 1 (0,5), 100 (2 registros) |
| Event value | 0 (83,5) y 13 valores más (6004, 1310, 5992, …) |
| Access Status | 2 (99,98), 0 (6 registros) |

Hecho numérico (no interpretación): muchos códigos de estado son potencias de
2 o sumas de ellas (4104 = 4096 + 8; 5120 = 4096 + 1024), lo que es
compatible con campos de bits; confirmarlo exigiría el manual del fabricante.

Relación empírica con la potencia (2017; ver `outputs/tables/eda_by_*_status.csv`):
con `Turbine status` = 0 la potencia es > 0 en el 99 % de los registros; con
1, 3, 33 y 35 es siempre 0; con 8 es > 0 en el 73 %.

## Variables derivadas (`R/04_features.R`)

| Nombre | Definición | Uso |
|---|---|---|
| `log_time` | `Log Time` parseado (ms normalizados), hora de reloj sin zona | eje temporal principal |
| `inv_time_utc` | `Inv Time` como segundos Unix (GMT) | solo comprobación |
| `log_minus_inv_hours` | `log_time − inv_time_utc` en horas | comprobación de coherencia |
| `date`, `year`, `month`, `hour` | componentes de `log_time` | descriptivo / posibles predictoras |
| `file_year` | año del nombre del fichero | trazabilidad |
| `source_file` | fichero de origen | trazabilidad |
| `dt_prev_s` | segundos desde el registro anterior | huecos |
| `starts_after_gap`, `segment_id` | inicio de tramo tras un hueco > 180 s; id. del tramo | dependencia temporal |
| `energy_increment_wh` | diferencia de `watt-hours` dentro de un tramo (puede ser negativa) | energía neta |
| `producing` | `power_out_w > 0` (indicador descriptivo, **no** estado documentado) | descriptivo |
